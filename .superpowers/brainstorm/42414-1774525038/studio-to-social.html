Studio → Social: How do generated assets flow to publishing?

ContentOS's unique advantage is AI Studio → Social Hub. A user generates an image in Studio, then wants to publish it. How does that handoff work?

A

"Publish to Social" button in Studio

After generating content in Studio, a button appears on the output node: "Publish to Social". Clicking it opens the full-page composer at /social/compose with the generated image/text pre-filled.

Media Library bridge

Studio saves generated assets to a shared Media Library. In the Social composer, users browse the library to attach assets. No direct button — assets are always available.

Both — direct button + media library
