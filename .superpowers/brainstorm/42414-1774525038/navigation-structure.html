Where does Social Hub live in the app?

Node Banana currently has a single /studio page with a full-screen canvas editor. The Social Hub needs its own space. How should we integrate it?

A

Sidebar Tabs (like Postiz)

Add a left sidebar with tabs: Studio (current canvas), Social (hub), Analytics (later). The sidebar collapses to icons. Each tab loads a different full-page view.

Pros

  • Clean separation between pillars
  • Familiar pattern (Postiz, Buffer, Hootsuite)
  • Scales to Analytics + Canvas pillars later

Cons

  • Takes horizontal space from the canvas editor
  • Bigger structural change
B

Top Header Navigation

Add tabs in the existing header bar: Studio | Social Hub. Click to switch between full-page views. Minimal structural change — reuses existing header.

🍌 Node Banana Studio Social Hub Analytics
Active tab content below header

Pros

  • Minimal change to existing layout
  • No horizontal space lost
  • Quick to implement

Cons

  • Header is already dense (file ops, save status, user)
  • Less room for social-specific navigation
C

Separate Route Pages

Social Hub lives at /social as its own page set (like /studio). Navigate via header links. Each pillar is a separate Next.js route group with its own layout.

🍌   /studio  →   /social  →   /analytics

Social Hub has its own sidebar nav within /social/*

Pros

  • Each pillar owns its layout and navigation
  • Social Hub gets a proper sidebar for its own sections
  • Clean Next.js route groups — easy code splitting

Cons

  • Full page navigation between pillars (not instant tab switch)
  • Need a shared top-level nav component
