Post Composer — How should the user create a post?

This is the core user flow. Postiz uses a modal that opens over the calendar. How should ContentOS handle it?

A

Modal Composer (Postiz style)

Click "New Post" → modal opens over current view. Compose text, add media, pick platforms, set schedule, preview, publish. Dismissible — calendar stays underneath.
