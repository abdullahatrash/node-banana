# 03: Compose and time a Secondary Video

**What to build:** A creator selects a second Workspace video, stacks it with the main video, trims and positions it in time, and saves and exports that two-video composition.

**Blocked by:** 01: Open, save, and export a main video.

**Status:** ready-for-agent

- [ ] Use Secondary video / الفيديو الثانوي consistently in media, timeline, timing, and source-audio labels; do not use Reaction as the track name.
- [ ] Limit the selected Secondary Video segment to 15 seconds while permitting the main composition to run up to 60 seconds.
- [ ] Provide a creator-selected start and basic trim; the segment plays once, disappears when it ends, and the main footage continues.
- [ ] Show stacked top-and-bottom panels inside the fixed portrait canvas. Preserve a consistent documented framing behavior in preview and export without silently ratifying new crop policies.
- [ ] Save/reopen preserves both media references, trim ranges, start time, and layout. Retain source audio at the corresponding composition times.
- [ ] Extend the main browser workflow using existing Workspace fixtures: scrub before, during, and after the Secondary Video, save/reopen, export, and inspect frames and source-audio windows. This ticket does not depend on the upload UI.
