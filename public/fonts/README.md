# Editor fonts

Fonts are served locally. Preview and export load the same selected file.

- `editor-arabic.ttf`: existing Noto Sans Arabic from `assets/fonts/creative/NotoSansArabic.ttf`; license in `assets/fonts/creative/OFL.txt`.
- `editor-cairo.ttf`: [Cairo variable font](https://github.com/google/fonts/tree/main/ofl/cairo), downloaded 2026-09-07; license in `cairo-OFL.txt`.
- `editor-naskh.ttf`: [Noto Naskh Arabic variable font](https://github.com/google/fonts/tree/main/ofl/notonaskharabic), downloaded 2026-09-07; license in `naskh-OFL.txt`.

Noto Naskh supports weights 400–700 and Cairo 200–1000; browsers map lighter requests to the nearest available weight. The existing Noto Sans Arabic supports 100–900.
