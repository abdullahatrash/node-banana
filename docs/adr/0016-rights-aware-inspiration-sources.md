# Use Rights-Aware Sources for Inspiration

Tasmeemai's Inspiration library will acquire trends through official APIs, licensed datasets, user-submitted links, lawful public metadata, and embeddable source media rather than covert or terms-violating scraping. Every **Inspiration Item** retains its source, capture time, metric freshness, rights status, and permitted remix behavior, and referenced media does not become a Workspace-owned Artifact merely because it is displayed. Remix begins from a **Remix Brief** that may reuse topic, hook, pacing, structure, and performance insight but excludes protected expression and carries transformation, attribution, Brand Profile alignment, and text/frame/audio similarity checks; this trades unrestricted collection and near-copy convenience for defensible provenance, platform compliance, and original Arabic-first output.
