# Versioned Content Format Definitions Drive Guided Creation

Every guided Tasmeemai format is governed by a versioned **Content Format Definition** that declares inputs, compatible Content Languages and Arabic Varieties, media constraints, preview schema, exact Workflow Revision, **Model Policy**, captions, duration and aspect limits, Managed Execution Quote policy, and editor handoff. The launcher, validation, Content Piece editor, admission preview, and tests derive from this contract rather than hardcoded React behavior. Curated model defaults may use friendly capability tiers, but exact provider, model/version, region, and evidence remain inspectable and Advanced overrides are limited to compatible operations. Batch generation produces sibling Candidate Outputs under one request or Content Piece Revision. Custom imports creator media into the normal Content Piece/Library/editing/publishing lifecycle while arbitrary Workflow authoring remains in the Cockpit. Media Sets reuse canonical blobs and Content Themes are licensed/versioned; consuming revisions pin exact membership and Theme version. Formats may ship separately only when their complete state matrix passes, and the adopted Fastlane baseline is not parity-complete until all eleven observed named formats plus Custom are complete.
