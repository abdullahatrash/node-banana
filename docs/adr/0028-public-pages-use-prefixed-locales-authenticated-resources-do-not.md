# Public Pages Use Prefixed Locales; Authenticated Resources Do Not

Tasmeemai uses locale-prefixed URLs such as `/ar/...` and `/en/...` for public, indexable marketing, Guide, Roadmap, and Release Note pages, with matching canonical and `hreflang` metadata. Authenticated product resources retain stable locale-neutral URLs such as `/dashboard` and `/content/...`; their Interface Language resolves from an explicit session choice, then the person's Workspace-specific Interface Locale Preference, Workspace default, supported browser preference, and finally Arabic. This preserves public discoverability and shareable localized entry points without making collaborative resource identity depend on a viewer's language. Changing Interface Language updates the durable preference and compatibility cookie but never Content Language or Arabic Variety.
