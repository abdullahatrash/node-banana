# Authored Message Catalogs Are Interface Language Authority

Tasmeemai's customer interface uses stable semantic message keys with complete authored Arabic and English catalogs; Arabic is the default Interface Language, document direction is derived from the selected locale, and product, billing, consent, security, validation, notification, email, and publishing messages resolve through the same catalog boundary on server and client. Runtime machine translation, inline customer-facing strings, and raw key rendering are not release fallbacks: missing required keys fail parity checks, machine assistance may only draft copy for qualified human review, and automated plus screenshot tests cover plurals, gender, interpolation, bidi isolation, logical layout, and RTL/LTR states.
