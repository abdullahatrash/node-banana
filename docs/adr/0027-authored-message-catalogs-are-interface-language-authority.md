# Authored Message Catalogs Are Interface Language Authority

Tasmeemai's customer interface uses stable semantic message keys with complete authored Arabic and English catalogs; Arabic is the default Interface Language, document direction is derived from the selected locale, and product, billing, consent, security, validation, notification, email, and publishing messages resolve through the same catalog boundary on server and client. Runtime machine translation, inline customer-facing strings, and raw key rendering are not release fallbacks: missing required keys fail parity checks, machine assistance may only draft copy for qualified human review, and automated plus screenshot tests cover plurals, gender, interpolation, bidi isolation, logical layout, and RTL/LTR states. Migration begins with shared shell, authentication, onboarding, common validation/error vocabulary, notifications, and common components; later vertical slices must extract every touched surface, while a CI allowlist of legacy literals may only shrink. If a defect escapes release gates, rendering falls back to the other authored catalog, emits a structured Localization Incident, and never exposes the semantic key; reviewed bilingual emergency templates protect mandatory security and billing communication.
