# Workspace Owns Commercial State

Workspace Subscription, Entitlements, recurring and purchased Generation Credits, storage allowance, API access, Channel and Automation limits, invoices, and commercial history belong to the **Workspace**, not an individual user identity. Human roles control purchase, plan administration, and invoice access while members and authorized Agent Principals consume Workspace capacity under separate authorization, Budget, Quota, and spend-grant checks; this prevents commercial state from moving ambiguously when a person joins, leaves, or switches Workspaces.
